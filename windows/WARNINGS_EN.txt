1. WHAT THE PROGRAM DOES

MailAllegati connects to a mailbox using the IMAP protocol with the credentials entered by the user, finds the emails coming from the senders chosen by the user, extracts their attachments and saves them in the folders chosen by the user and, if enabled, copies them to a network device (NAS) using the SMB protocol.
The program does not send data to third parties: it only communicates with the configured mail servers and NAS and, if the update check is enabled, with GitHub to find out whether a new version exists.


2. HOW TO USE IT

a) Enter IMAP server, port, user and password of your mailbox and press "Test email connection". You can add more than one mailbox.
b) Enter the senders to check, one per line: full address (e.g. invoices@company.com) or domain (e.g. @company.com). To send a sender to a dedicated folder add "= folder" (e.g. @company.com = Bills\Power).
c) Choose one or more destination folders. Attachments are saved in all the folders listed.
d) Optional: enable the NAS by entering path (e.g. \\192.168.1.10\share\attachments), user and password, and press "Test NAS connection".
   If the NAS is off or unreachable, attachments are queued on the device and sent automatically as soon as the NAS is reachable again. The queue takes space on the device; on Android it is deleted if the app is uninstalled or its data is cleared. The "Send to NAS now" and "Empty queue" buttons let you manage it manually.
e) Start monitoring. On Windows the check runs while the program is open (also minimized or started with Windows). On Android it runs in the background, at most every 15 minutes, according to the system power-saving rules.
f) By default only emails arriving after activation are processed. The option "also process the emails already in the mailbox" retrieves the attachments of existing emails.
g) Check the "Activity log" from time to time to make sure everything works correctly.

- Make sure the destination folders and the NAS have enough free space. The program does not handle running out of space.
